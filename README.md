# NEO Tracker website

Static pages for the NEO Tracker iPhone app, served by GitHub Pages:

- `index.html`: about the app
- `privacy.html` / `datenschutz.html`: privacy policy (English / German), the same text as the app's in-app policy
- `support.html`: support and contact

Keep the privacy policy in step with the app's `PrivacyPolicyView` (AboutViews.swift) when either changes.
